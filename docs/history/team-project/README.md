기준 커밋은 `980da07edbc709e79713a1897b07e73145280336`이다. Git 이력은 변경하지 않는다.

이 폴더는 현재 에이전트 지침이 아니다. Sprint 경계, Java 변경 제한, 팀 승인 등 과거 지시를 현재 작업에 적용하지 않는다.

팀 개발 결과와 교육용 템플릿 출처를 개인 기여로 바꾸지 않는다. 새 개인 개발은 기준 커밋 이후의 변경으로 구분한다.

기록 속 상대 링크는 원문을 유지했으므로 이 폴더 기준으로 열리지 않을 수 있다. 원본 경로는 manifest와 기준 커밋에서 찾는다.
